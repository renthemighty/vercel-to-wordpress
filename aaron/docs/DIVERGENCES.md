# Recorded divergences from the original sites

BUILD_SPEC.md is explicit that nothing may be silently omitted or silently resolved. Every
place the converted site deliberately differs from the original is listed here, with the
reason. `tools/verify_structural_diff.py` reads this register, so an entry here suppresses a
gate failure and nothing else does. Removing an entry re-arms the gate.

Anything NOT in this list that the gate flags is a real defect, not an accepted difference.

## 1. Cart and checkout are real WooCommerce

**Original:** a localStorage cart and a checkout holding page reading "Card payment is the
last piece being connected, so nothing can be charged here yet", falling back to emailing
hello@<brand>.com for a manual invoice.
**Converted:** real WooCommerce cart and checkout.
**Why:** Aaron's explicit decision. This conversion is the move off Vercel onto hosting with
a payment gateway, which is what both brands were waiting for. A faithful conversion would
have reproduced a dead end.
**Status:** intended. Payment gateway still to be connected on the live store.

## 2. Mobile navigation added

**Original:** both sites hide `.nav__links` below 860px and put nothing in its place, so a
phone visitor can only navigate from the footer.
**Converted:** a `<details>` disclosure menu reusing the same links, styled from each brand's
own button rule.
**Why:** a store you cannot navigate on a phone is a defect, and mobile is the priority
surface. Remove the `.navmob` block in `tools/build_theme.py` for exact parity.
**Status:** intended. A visual gate will flag the header on narrow widths.

## 3. Set savings copy moved from the listing to the product page

**Original:** `sets.html` prints, per set, "Bought separately at entry size these come to
$X. The set is $Y, so you keep $Z, which is N percent off."
**Converted:** the same sentence, recomputed from the catalogue, on each set's product page.
The Sets category archive shows cards only.
**Why:** the archive is generated by WooCommerce from the catalogue. Injecting per-product
editorial into an archive template means maintaining a second copy of the pricing maths that
goes stale the moment a price changes. The product page is where a buyer decides, and the
figure is derived at build time from the same catalogue the prices come from.
**Status:** intended, content preserved and relocated, not dropped.
**Gate:** suppresses `/sets.html` on both brands.

## 4. Category labels stay plural

**Original:** product cards print a singularised category, and the naive trailing-s strip
produces "Charms & Extra".
**Converted:** the real category name, "Charms & Extras".
**Why:** reproducing a typo is not parity worth having.
**Status:** intended. Shows up as minor word differences on listing pages.

## 5. Front page product rails are live queries

**Original:** hand-picked product lists baked into `index.html` at build time.
**Converted:** WooCommerce queries.
**Why:** a frozen copy of the catalogue in page content goes stale the first time a price or
a product changes.
**Status:** intended.
